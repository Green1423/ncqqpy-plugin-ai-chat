# ai_chat 插件

> 上级：[插件文档](README.md)

> 版本 1.0.0 · 依赖框架 ≥ 1.0.0
把 DSH（DeepSeek Harness）的对话语义搬进 QQ：**多会话**、**DSH 式消息包装**、
**上下文压缩**、**内置工具（function calling）**。对话不需要命令前缀，
但需要**结束符**收尾；管理动作才走命令。
