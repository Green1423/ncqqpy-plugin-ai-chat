# 十二、Markdown 模式

> 文档索引：[docs/README.md](https://github.com/Green1423/ncqqpy/blob/main/docs/README.md) · 上级：[ai_chat 插件](README.md) · 上一章：[联网搜索](11-web-search.md) · 下一章：[`/md`：把上一条 AI 回复转成图片](14-md-image.md)

AI 默认用纯文本回复（QQ 不渲染 Markdown）。开启 Markdown 模式后，回复会先渲染成
一张图片再发出，适合表格、公式、代码块较多的问题。

## 12.1 使用方式

在结束符后加 `md`：

```text
请用表格对比三种方案//md
```

`//md` 是「提交 + 图片输出」的组合；不加 `md` 则按普通文本模式回复（自动降噪，
见 12.3）。结束符与后缀都可以配置：

```json
"plugins": {"ai_chat": {"trigger": {"terminators": ["//"], "markdown_suffix": "md"}}}
```

`markdown_suffix` 留空则关闭 Markdown 模式。

## 12.2 输出效果

- 整段回复渲染为**一张图片**发送；
- 图片宽度按内容自适应，标题、列表、表格、公式、代码块分别排版；
- 超长内容会先分段再渲染，避免单图过高；
- 渲染失败（例如运行环境缺少浏览器）时自动降级：先说明原因，再把原文按普通
  文本模式发出，不会丢内容。

## 12.3 文本模式（不加 `md`）的降噪

普通文本模式下，Markdown 标记会被清理成适合 QQ 的样子：

| 输入 | 输出 |
|------|------|
| `**重点**` | `重点` |
| `> 引用` | `引用` |
| `[文档](https://example.com)` | `文档（https://example.com）` |
| `` `代码` `` | `代码` |
| `---` | 一条分隔线 |
| `\*` 等转义 | 还原成 `*` |

数学公式整段保护、原样保留（`$a*b$` 里的 `*` 不会被当成强调）。

## 12.4 会出图的内容

文本模式下，以下块如果原样发出去会变成一堆符号，因此单独出图并插回原位置：

| 内容 | 触发 | 不出图会变成 |
|------|------|-------------|
| 表格 | 表头 + `---` 分隔行 | 一堆竖线 |
| 块级公式 | `$$…$$`、`\[…\]`、单独成行的 `$…$` | 反斜杠与 `$` |
| 标题 | `###` 及以上（`#` / `##` 视为正文） | 一串井号 |
| 列表 | 连续 ≥2 行 `- ` / `1. ` | 一堆破折号 |
| 代码块 | ```` ``` ```` 围栏 | 反引号 |
| 行内公式 | 正文里的 `$…$` | LaTeX 源码 |

- 列表/代码块里的公式随整块出图，不再单独出小图；
- 行内公式渲染成小图与文字交错排列，保持原文顺序；
- 表格、公式图片会缓存，同一内容不重复渲染。

## 12.5 与 `/md` 的区别

- `//md`：提交时就决定用 Markdown 模式，回复直接以图片发出；
- [`/md`](14-md-image.md)：把**上一条已发出的回复**重新渲染成图片，适合事后才发现
  排版乱掉的情况。

## 12.6 已知限制

- 图片渲染需要 Chromium（或同类无头浏览器），未安装时自动降级为文本；
- 公式支持 LaTeX 子集（KaTeX），复杂宏包命令可能渲染为源码；
- 宽度过大的表格会等比缩放，字号可能偏小；
- 图片消息不能像文本一样被引用回复，需要引用时请用文本模式。

## 出图宽度：永远等于版心宽（720）

线上 `s0037` 的 md 图是 **870×1224**（版心 720），右侧多出一片空白、看起来像被裁了。
根因不是宽度算法，而是 **KaTeX 额外生成的那份 MathML**（`<math>`，给读屏用的）：
它本应由 KaTeX 的 CSS 隐藏（`clip: rect(1px,1px,1px,1px)`），一旦那份 CSS 没到位
（离线/自带资源缺失/CDN 挂掉），这个元素会按**块级**排版、把页面撑到 870。

修法（`markdown_body_css()`）：

```css
.katex-mathml, .katex-html .katex-mathml { display: none !important; }
```

另外代码块不再用 `overflow-x: auto`（滚动容器里的内容**仍被算进宽度**），
改成 `white-space: pre-wrap` 换行显示 —— 否则一段长代码同样把整页撑宽。

验证：普通段落 720×373、行间公式 720×271、`s0037` 那条长答案 720×1224。
